# Data Structures in C++

A collection of data structures implemented from scratch in C++ to understand their internal working, memory management, and core concepts instead of relying on the STL.

## 🎯 Purpose

The goal of this repository is to build data structures from scratch and understand:

- How they work internally
- How memory is allocated and managed
- Time and space complexity
- How pointers and dynamic memory are used
- How different data structures solve different problems
- How real-world STL containers are conceptually built

## 🛠️ Language & Tools

- **Language:** C++
- **Compiler:** GCC / G++
- **Concepts:** Templates, Dynamic Memory, Pointers, OOP, Data Structures
